# AI_Project - Sistema de Recomendación con GitHub Copilot

## Descripción

Actividad formativa realizada para explorar el uso de GitHub Copilot como herramienta de inteligencia artificial aplicada al desarrollo de software.

El proyecto consiste en un sistema simple de recomendación de productos desarrollado en Python con apoyo de GitHub Copilot.

## Herramientas utilizadas

- GitHub
- GitHub Copilot
- Visual Studio Code
- Python
- Pandas
- Scikit-learn

## Desarrollo de la actividad

1. Se creó el repositorio `AI_Project` en GitHub.
2. Se clonó el repositorio en Visual Studio Code.
3. Se creó el archivo `recommendation_system.py`.
4. Se utilizó GitHub Copilot para generar el código inicial.
5. Copilot generó un sistema de recomendación utilizando KNN.
6. Se instalaron las dependencias necesarias.
7. Se ejecutó el programa para comprobar su funcionamiento.

## Funcionamiento

El sistema utiliza datos de ejemplo de distintos productos y considera características como:

- Precio
- Valoración
- Popularidad

A partir de estos datos, el sistema busca productos similares a las preferencias indicadas y entrega recomendaciones.

## Resultado

El programa fue ejecutado correctamente y generó recomendaciones de productos según los datos ingresados.
